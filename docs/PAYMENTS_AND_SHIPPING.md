# Payments (Razorpay) & Shipping (Shiprocket) Integration Guide

Aaranya Spices is architected for Indian D2C commerce with support for **UPI, Cards, NetBanking, and Cash on Delivery (COD)** as well as **pan-India PIN code dispatch**.

---

## 1. Razorpay Payment Gateway Setup

### A. Set Supabase Edge Function Secrets
After creating your API keys in the [Razorpay Dashboard](https://dashboard.razorpay.com/), register them as secrets in your Supabase project:

```bash
npx supabase secrets set RAZORPAY_KEY_ID=rzp_test_xxxxxxxx
npx supabase secrets set RAZORPAY_KEY_SECRET=xxxxxxxxxxxxxxxx
npx supabase secrets set RAZORPAY_WEBHOOK_SECRET=your_webhook_secret
```

Add the public key to your frontend `.env`:
```env
VITE_RAZORPAY_KEY_ID=rzp_test_xxxxxxxx
```

### B. Payment Flow Sequence
1. Customer completes the checkout form on `/checkout` ([`src/pages/CheckoutPage.tsx`](../src/pages/CheckoutPage.tsx)).
2. [`submitOrderToProvider`](../src/services/checkoutService.ts) creates the order record (`payment_status = 'PENDING'`) in Supabase PostgreSQL and decrements SKU inventory via the `decrement_variant_inventory` RPC function.
3. For prepaid methods (`upi`, `card`, `netbanking`), invoke the `create-razorpay-order` Edge Function ([`supabase/functions/create-razorpay-order/index.ts`](../supabase/functions/create-razorpay-order/index.ts)) to obtain a `razorpayOrderId` and open the Razorpay Checkout modal.
4. When payment succeeds, Razorpay calls the `verify-razorpay-webhook` Edge Function ([`supabase/functions/verify-razorpay-webhook/index.ts`](../supabase/functions/verify-razorpay-webhook/index.ts)), which verifies the HMAC-SHA256 signature and updates `payment_status = 'PAID'`.

## 2. Shiprocket Courier & AWB Tracking

### Manual Fulfilment via `/admin` Console
1. Open `/admin` (**Operations & Inventory Console**).
2. Under the **Orders** tab, enter the courier **AWB Tracking Code** generated by Shiprocket/Delhivery.
3. Click **`PACKED`**, **`DISPATCHED`**, or **`DELIVERED`** to update the order status in Supabase PostgreSQL.

### Automated Shiprocket API Hook
To automate AWB creation upon payment capture, add your Shiprocket API user credentials to Supabase secrets:
```bash
npx supabase secrets set SHIPROCKET_EMAIL=logistics@aaranyaspices.com
npx supabase secrets set SHIPROCKET_PASSWORD=your_api_password
```
Then extend `verify-razorpay-webhook/index.ts` to POST the confirmed order payload to `https://apiv2.shiprocket.in/v1/external/orders/create/adhoc`.
